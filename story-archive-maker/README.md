# Story Type Test / ポーネグリフメーカー

直感で選ぶ全7問から、四桁の物語コードと自己診断を生成する無料Webアプリです。

## App

https://kujo-jotarou.github.io/web-uranai/story-archive-maker/

## 診断でわかること

- 3301〜4101の物語タイプ
- 自分の強み
- ハマりやすい罠
- 創造・接続・再生の3つの傾向
- 今日できる「最初の10分」

## Privacy

- 完全無料・登録不要
- 回答と診断はブラウザ内だけで処理
- 回答や診断結果をサーバーへ送信・保存しません
- 解析用トラッカーなし

## Project note

エンタメ用の自己診断・創作ツールです。医療的・心理学的な診断ではありません。画面、石板、記号、文章、診断ロジックは独自制作です。
